#+title: Graph algorithms and incremental publication

* Contract

A node is a key in a finite POO declaration. An edge from A to B means A
declares a read of B. A dependency change can invalidate A even when A
lies outside the region whose topological order or SCC membership changes.

An edit produced by the existing Graph API can reuse the previous snapshot's
indices. The local path checks the edited rows and visits the affected
dependencies and consumers. A replacement without matching source evidence
uses full validation. Full enumeration of order or groups has its own cost.

An SCC uses its first member in source order as representative. The
condensation graph schedules dependencies before their consumers. A failed
admission or superseded request leaves the current publication intact.
Readers observe graph and metadata from the same published snapshot.

* Topological order, components and publication

For edge edits on a fixed set of owners, the SCC repair region is
=R = Reach(U,D) ∩ Reach(reverse(U),D)=. =U= contains the old and new edges,
and =D= contains owners whose outgoing edges changed. Recompute SCCs inside
=R= and retain membership outside it. Value invalidation follows reverse
edges from changed inputs and edited readers, including consumers outside
=R=.

* Performance

CPU milliseconds from paired Scheme measurements with equivalent prepared inputs.
The chain uses verified source order to label singleton SCCs. The cyclic
band uses bulk retirement once Algorithm T establishes a single component.
The feedback revision reuses the published inverse index to find consumers.

|-----------+-------+----------+-----------|

| Feedback revision, one base edit and its consumer | 10K groups | 10.775–13.505 | 0.505–0.636 |

* Relation to POOF

Rideau, Knauth and Amin describe selective invalidation in POOF §6.2:

#+begin_quote
the system can automatically track which mutations happen, and invalidate those caches that need be
#+end_quote

POO applies this to declared reads and tracked revisions. The reverse
dependency index identifies consumers of an edited input. Graph repair updates
the order or SCC partition, and publication checks that the edited snapshot
is still current. [[https://github.com/metareflection/poof/blob/532e0c8aa6f3168e374604cb8aa7818870694bf6/poof.scrbl#L1527-L1556][POOF §6.2, Cache invalidation]]
