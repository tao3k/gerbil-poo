#+title: Component publication: final lineage check after admission

An approval callback can finish after another thread has restaged the same
request family. A denied replacement keeps the installed head but cannot
restore the predecessor's ticket. This is distinct from a rival family
installing a new head, which the installed snapshot identity already detects.

| Model | Scheme boundary |
|-------+-----------------|
| =Current= combines owner, epoch, family version | =require-request!=, =request-current!= and =require-version!= |
| =advance_retires=; =advance_keeps_sibling= | =restage= advances one lineage while holding the domain lock |
| =failed_replacement_cannot_restore=; =head_only_misses_restage= | callback runs outside the lock; final =request-current!= cannot be replaced by only =require-current!= |
| =install_whole=; =old_epoch_rejected= | one =%publication-head-set!= installs the entire immutable graph/metadata pair |
| =reader_after_commit_rejects=; =reader_with_revoked_guards_rejects= | =call-with-snapshot= rechecks the head and independent guards before releasing results |

[[file:component-publication.lean][Lean]] composes the existing serialized
installation contract across the same-head failed-replacement trace. Epochs
stand for fresh Scheme snapshot identities. The Boolean at =commit= stands
for the independent final guard and currentness decisions under the lock;
it is not the author callback's earlier approval. Lean does not verify the
mutex, source admission, dependency computation, or mutation of external
objects. [[file:component-publication.sysml][SysML]] records those boundaries.
No existing QNT transition or Scheme implementation is changed.

The test uses channels to pause the old submitter in approval with a real
value delta. Another thread restages and denies a replacement. The original
must report =stale component revision ticket= while returning the exact old
head; a fresh approved restage then installs the new graph and metadata
together. Both graph and metadata in the original snapshot remain readable.

The matched native fault keeps the final head check, but removes the final
lineage check. The new test fails because the obsolete thread returns a
different installed snapshot. Two existing reentrant oracles also fail.
The fault compiles successfully and the Just suite exits 1, without timeout.
