Unfactored constructors reconstruct the original input/output Types and Formula on each call;
prototype specialization shares these invariants and supplies a fresh dependent meaning.
Controls check the same positive calls and input refusals before constructor-only timing.
Complete joint controls build three generics, two descriptors and two bound wrappers, run real
joint approval, and make identical checked reserve/cancel calls. No changed approval is skipped.
Binding isolation includes the real key/current-state executor adapter and metadata.wrap.
Stage batches have independent GC histories; their medians cannot be summed as a request decomposition.
Workflow controls also refresh the 15-node DAG: 3 evaluated, 12 reused, then the same joint publication.

Selector weights are explicit operation prices; selection is charged, ties keep shared. Direct/shared
semantics must agree for every closed input. Lean proves that equality and conditional cost bounds,
including once-only template validation and amortization; it does not prove these CPU timings or cold process startup.
The dynamic selector is optional and is not promoted to the default strategy. Final selected-vs-independent
raw natural CPU regressed about 15 percent (255.750 vs 222.422 us); collected differs about 0.4 percent.
Natural per-round collection counts differ sharply: selected/independent = 1/0, 21/0, 31/31, 24/32.
Those histories prevent attributing the full total-CPU gap to selector arithmetic. Full GC receipts stay ignored.
Invariant metadata reuse is the primary measured gain, not a universal selector speed guarantee.
