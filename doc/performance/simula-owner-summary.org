* Preceding bound-owner implementation and evidence

** Three-way correspondence and scope
This advances generalized-protocol future work. Racket reference: poof revision
9affa8fbbb4f12cbd98cb97f8b8b84474fc39429, poof.scrbl 2040–2099: negative
assumptions, method fragments and effective methods. No successful invocation
result is memoized. The Scheme package has no Lean checkout dependency.

Native prepared-context uses the existing Invocation. specialization protocol.
compile-simula-context compiles prefix/suffix callbacks once using foldr/foldl;
bind-context validates each immutable current Object and retains the exact method
index, signature, precedence and candidate/effective caches. Current units, guards,
business checks and Unit output still execute at every call. Context-sensitive
applicability belongs in Args. Nested cache transport rejects context replacement;
new data enters through checked reconstruction and publication.

methods.refresh<-sized-projection keeps the original native eq backend, using its
ordinary size hint as Gerbil's expander does. On owner handoff it stages ALL freshly
constructed, registered and negative-checked cells. Comparable nonempty service
storage is privately copied, old-only keys pruned and every current cell overwritten.
Expansion/contraction/empty support uses fresh sized storage. Old storage confers
no certificate; failed staging publishes nothing. Initial construction, same-owner
reuse and approvals retain the existing protocols. No global selector is installed.

* Proof and semantic controls
Lean compileParts_contramap / bindSimula_correct preserve arbitrary lists and
lawful effects, including callback order and refusal. PreparedContextMultimethod
proves program preservation, both cache invariants, reference-call equivalence,
warm owner retention and current context preservation. The nested context-change
law refuses a changed context on cache-only transport.

GenericFamily.emptyWithCapacity_lookup proves capacity supplies no entries.
overwriteStorage_current / rebuiltLookup_reference prove fully overwritten,
masked/pruned storage has the fresh reference lookup. rebuiltLookup_certified
constructs authority only from the freshly checked reference. This typed model
does not verify native hash copying, compiler code generation or the collector.

and excess collections. binding_covered requires hot saving to pay the whole
horizon; tables_covered combines only independently supplied favorable table prices.
The illustrative prices are not embedded in Scheme and prove no elapsed time.

* Fixed native paired protocol
13 scenarios, six direct pairs, four ABBA rounds, natural and collected regimes:
1248 fresh children / 624 pairs. Every child initializes and warms the same ten
controls in the same order before timing one side. First handoff, later revision,
eight-request publication, 256-request publication, actual switched-owner hot calls,
unchanged reuse and GC-free one-shot allocations are separate scenarios.
The 256-request horizon uses 16 fixed repetitions; hot scenarios use 1024; ordinary
publication phases use 64. No timing-dependent adaptation or best-run admission.
Every reserve executes the contract, body and actual cache-budget readmission.
Prefix counters, A/A controls, completion, source/binary digests and EOF are checked.
Admission requires both sides GC-free for byte deltas; all admitted byte pairs
below have four pairs per regime. Different phase medians are NOT additive: the
isolated generic/contract controls receive precomputed inputs, unlike full publication.

handoff, 32 more on later revision and 96 fewer on each switched-owner hot call.

report to 768 bytes. Generic-only allocation fell 1232 bytes against staged;

* Adverse experiments retained as separate evidence
The symbolic-table trial allocated +4000 bytes (sizing) / +10272 (bound) against
staged on first handoff. Fixed-seed symbolic storage with shared prepared context
still cost +4576 / +4704. Both backend choices were rejected. Returning to original
eq tables with size hints reduced these to -192 / -64, but left +2128 against pure
compiled-context. Isolated controls located that difference in generic construction,
not contract binding. Private checked-cell staging and workspace copying then
reduced pure-context excess to +768. No timings from different sources are pooled.
The earlier workspace study's eight-request publication was adverse in BOTH
regimes (+22.344 / +6.703 us); this remains evidence against a universal default.
The first 1248-child burst study (before correcting an explanatory comment only)

-0.227 / -0.310 us against staged. Its collected burst improved only 2/4 pairs.

required to describe reference-call preparation accurately. No results are pooled
