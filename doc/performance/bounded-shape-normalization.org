* Change and proof

Small shape preparation allocated a fresh symbolic membership table even
when all receiver shapes reused the existing canonical index. For at most
eight names, =object/slot-layout.ss= now uses Std =foldr= with Scheme =memq=.
Larger name sets and hint-based updates retain their original hash algorithm.
The bounded path performs at most 28 membership comparisons; no quadratic
algorithm is applied to a large directory.

Right-to-left admission, first refusal, last-occurrence order, the native seed
draw, canonical sorting, independent receiver cells and the one weak interner
are preserved. Unknown native-construction routes fall back as before.
There is no new cache, loader, source interface, public flag or runtime carrier.

[[https://github.com/tao3k/lean-poo/blob/d508e976c6aa99a1ac26af76a958f24db7232d9f/LeanPoo/Proof/Gerbil/ShapeAdmission.lean#L283][ShapeAdmission.BoundedNames at d508e97]] in Lean-POO proves hash/list membership coherence,
state/error equality, bounded/hash selection, the seed prefix and arbitrary
continuations after equal normalization. New theorem axioms are =propext=
and =Quot.sound=. Native route/primitive conformance remains an executable
obligation; the proof does not establish host timing, allocation or compilation.
