#+title: Generator composition cost admission

* Scope and controls

=just benchmark-generators 20 4= uses the existing shared executable,
=module-action= and =closure-measure= process-statistics helpers. No new runner,
process scheduler, environment setting, JSON dataset or archive is introduced.
The complete entry includes standard library preparation and first module load.
Per-phase results separately measure sampler preparation, reused drawing, and
preparation plus complete falsification/shrinking.

Both callback and tree strategies use the SAME injective two-UInt product,
constant draws, seed, admission, measure and property. Each complete run must
produce the exact false witness =#(0 3)=, ten proposals, three accepted descents
and observed local exhaustion. This is a common-domain comparison, not evidence
that output-only shrinking can invert arbitrary non-injective mappings.

Each phase retains AB/BA, A/A and B/B. Natural GC is untouched. Post-GC batches
record collection preparation and the first invocation separately and charge
both in the summarized totals. CPU, wall, GC, collections and allocation remain
available in the ordinary Scheme output. Raw logs stay outside Git.

* Source admission changes

Initial compositions nested source-check callbacks. The core now retains flat
leaf observers and uses standard identity-hash deduplication. Rejected proposals,
earlier successful trials and rejected draw branches retain their observers.
Caller-owned source-list mutation cannot edit stored node ownership. Bounded
recursive derivations prepare scalar bridges once per captured graph.

POO additionally prepares the optional =.current?= hook once. Its source revisions
are checked before every use, so an overridden hook does not gain fresh authority.
These mechanisms reduce repeated preparation without a global source cache.
The existing stale/EOF/zero-fuel tests and identity-union laws retain the failure
semantics. They are not proofs of callback termination or runtime hash behavior.

P0 functional/finite-proof admission and performance admission remain separate.
Further optimization must retain branch provenance, all visited source epochs,
strict failure classification and identical proposal counts. It must not silently
choose value-only shrinking for an arbitrary mapped or dependent generator.

* Seed preparation repair, 2026-10-28

The reproduced pre-repair natural workflow delta was +73784.11 us per twenty
checks (range +69509.98 to +79569.34). CPU was +73494.00 us, comprising
+33602.00 us GC and +39892.00 us remaining CPU; extra allocation was 101538118
bytes. This is a repeatable work difference, not merely GC history or wall noise.

The seed-isolation probe uses only SRFI-27 source/state operations. A preliminary
no-GC twenty-source control took 3719 us and 9037168 bytes when reseeding, versus
13 us and 37216 bytes when restoring a previously prepared checkpoint. That
control excluded checkpoint preparation and therefore is diagnostic only. The
committed =GENERATOR-SEED-PAIR= probe includes one checkpoint preparation INSIDE
every restore batch, fresh sources for every draw, AB/BA, A/A, B/B and charged
post-GC preparation/first calls. Its deterministic draw oracle is identical.
The [[https://srfi.schemers.org/srfi-27/srfi-27.html][SRFI-27 specification]] owns
state representation; the implementation does not inspect or persist it.

Bind now captures an invocation-owned standard identity-by-value hash table of
initial states, shared with nested bind regeneration through an ordinary Scheme
parameter. A later branch restores a NEW mutable random source. The checkpoint
table is retained only with that invocation's sample tree, never globally or
across property runs. Seed splitting, selectors, draws, source checks, proposal
order and failure classification remain in the existing bind/map implementation.
No generated value or callback outcome is memoized. A checkpoint is inserted
only after successful expansion.

Source preparation also shares empty/identical INTERNAL normalized observer
lists. Public observer inputs/exports are still copied, with both singleton and
multi-leaf alias-mutation controls. No observer is omitted or accepted on the
basis of a previous Boolean result. Pure constant units expose their existing
empty child list directly, and identity mapping can reuse a node only when it
adds no source ownership. The attempted direct-cursor replacement did not explain
the large regression and was discarded; coroutine traversal remains unchanged.

Regressions retain independent sibling streams after unequal draw counts,
repeated traversal and a fresh root, unchanged selector/draw invocation counts,
unused-tail laziness, first interruption, zero fuel, rejected proposals, stale
sources and replay refusal. Lean proves cache-content/insertion invariants,
checkpoint-regeneration equivalence including consumed states and first failure,
and source-join freshness. State restoration is an explicit runtime obligation;
no theorem claims host PRNG quality, callback termination, GC or elapsed time.
