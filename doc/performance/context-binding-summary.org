* Fixed controls and evidence boundary
Three complete final-source runs were fixed before measurement; each admits
576 children (12 phases, two GC regimes, four rounds, three pairs, two positions).
Fresh child per side, common setup and four warmups of all four controls, ABBA
side order and exact duplicate A/A procedures. No local build/test overlaps these
measurements. Bounds: 90s AOT, 90s each study, 20s and 1GiB per child, unchanged.
The existing native paired I/O and Gambit statistics implementation is shared.

Reference controls retain the parent Reader bind/pure algorithm and public
=bind-observer= (unchanged); no forced synthetic allocation is introduced.
Both nested controls already have a prepared snapshot and fixed-base reader.
Revision compares a reusable current-context reader against a new fixed-base
reader for EACH of eu/us, using the SAME precompiled graph. One action observes
two contexts. Factory includes a fresh prepared snapshot and reader plus the
actual public observation. Preparation uses exactly the SAME action on both
sides and isolates fresh descriptors/slot-cache setup over a common already
warm declaration graph. It does not measure first module load or cold C3 nodes.

=nested-history= performs 64 real reference observations before the common
warmups; no forced GC in natural mode. Collected performs one premeasurement GC;
it cannot equalize heap shape, finalizers, page residency or all runtime history.
Signed byte deltas are admitted only when BOTH paired intervals have no GC and
nonnegative counters. A missing allocation pair is not zero allocation. A/A
variation and prefix mismatches remain diagnostics; they do not establish a
cause. CPU minus measured GC CPU still includes allocator/memory effects.

* Standalone native reproduction
Run from this Gerbil checkout with Homebrew Gerbil, GNU timeout and OpenSSL 3;
no Lean installation or checkout is used. AOT output must be fresh:

#+begin_src sh
GERBIL_PATH="$PWD/.build/env" just build
GERBIL_PATH="$PWD/.build/env" just test
study_dir=$(mktemp -d "$PWD/.build/context-binding.XXXXXX")
GERBIL_PATH="$PWD/.build/env" env -u SDKROOT -u CPATH -u LIBRARY_PATH \
  -u C_INCLUDE_PATH -u CPLUS_INCLUDE_PATH -u MACOSX_DEPLOYMENT_TARGET \
  COMPILER_PATH=/usr/bin gtimeout --signal=TERM --kill-after=3s 90s \
  gxc -d "$study_dir" -exe -ld-options '-L/opt/homebrew/opt/openssl@3/lib' \
  -o "$study_dir/paired" t/binding-benchmark.ss
# Finish builds/tests first. Predeclare all three runs and retain adverse results.
for run in one two three; do
  GERBIL_PATH="$PWD/.build/env" gtimeout --signal=TERM --kill-after=3s 90s \
    gxi -:max-heap=1G,debug=q t/binding-suite.ss "$study_dir/paired" \
    /opt/homebrew/bin/gtimeout "$study_dir/$run.scm" > "$study_dir/$run.log" 2>&1
done
#+end_src
